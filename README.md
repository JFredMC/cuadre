# Cuadre

Calculadoras laborales y de seguridad social para Colombia (liquidación, salario neto, prima, intereses de cesantías, horas extras y recargos, aportes de independientes). Sitio estático en Angular, prerenderizado para SEO y publicado en GitHub Pages.
